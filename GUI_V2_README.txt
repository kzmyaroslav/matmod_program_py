MATMOD GUI V2
=============

Это обновлённая визуальная версия GUI.

Что изменено:
- современная тёмная тема;
- верхняя панель с названием приложения и статусом;
- отдельная боковая панель параметров;
- карточки результатов;
- вкладки ОБЗОР / КАРТА / 3D;
- более компактные формы;
- визуальная индикация состояний ГОТОВО / РАСЧЁТ / ОШИБКА;
- сохранены существующие расчётные модули.

Установка:
    pip install -r requirements.txt

Запуск:
    python gui_main.py

Старый CLI:
    python main.py

Заменить в репозитории:
    gui/__init__.py
    gui/main_window.py
    gui/source_widget.py
    gui_main.py
