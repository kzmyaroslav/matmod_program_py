ГРАФИЧЕСКИЙ ИНТЕРФЕЙС
======================

1. Установка зависимостей
-------------------------

В корне проекта выполните:

    pip install -r requirements.txt


2. Запуск GUI
-------------

В корне проекта:

    python gui_main.py

Старый консольный режим при этом не изменяется:

    python main.py


3. Что умеет первая версия GUI
------------------------------

- задавать размеры помещения;
- задавать шаг расчётной сетки;
- выбирать расчётную плоскость XY/XZ/YZ;
- задавать координату расчётной плоскости;
- создавать от 1 до 3 источников;
- выбирать тип источника:
    SPHERE
    DISK
    CYLINDER
    HEMISPHERE
    HALF_SPHERE
- выбирать INTENSITY или FLUX;
- вводить параметры, необходимые конкретному типу источника;
- запускать расчёт;
- показывать Emin, Emax, Eavg;
- показывать Emin/Emax и Eavg/Emax;
- показывать карту освещённости;
- показывать 3D-визуализацию;
- сохранять Excel и изображения в папку results;
- открывать созданный Excel и карту из интерфейса.


4. Архитектура
--------------

GUI не дублирует расчётные формулы.

Используются существующие модули проекта:

    models/
    photometry/
    calculation/
    visualization/
    output/

Файл main.py специально не изменяется.


5. Важное ограничение первой версии
-----------------------------------

Сейчас GUI является интерфейсом расчёта.

Оптимизация положения источника пока не включена.

Её можно добавить отдельной вкладкой после проверки работы базового GUI.
